# 🧹 Data Cleaning — Messy Dataset

## 📌 Project Overview

This project demonstrates professional **data cleaning and preprocessing** by transforming a deliberately messy dataset into a clean, analysis-ready dataset.

The project documents each cleaning decision and compares the dataset before and after cleaning.

## 🎯 Objectives

- Perform a complete data quality assessment
- Identify and handle missing values
- Detect and remove duplicate records
- Standardize inconsistent values and formatting
- Detect and handle numerical outliers
- Correct incorrect data types
- Create a before-vs-after data quality summary
- Export the cleaned dataset as a CSV file

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Jupyter Notebook

## 🔍 Data Quality Checks

The project checks for:

- Missing values
- Duplicate rows
- Incorrect data types
- Inconsistent formatting
- Invalid values
- Range anomalies
- Numerical outliers

## 🧹 Cleaning Techniques

The dataset is cleaned using:

- Mean / Median Imputation
- Mode Imputation
- Forward Fill
- Duplicate Removal
- Value Standardization
- Date Conversion
- Data Type Correction
- IQR / Z-Score Outlier Detection

Each major cleaning decision is explained in the notebook using Markdown cells.

## 📊 Before vs. After Analysis

A comparison table is created to show:

- Null count
- Duplicate count
- Row count
- Data type accuracy

This demonstrates how the data quality improved after preprocessing.
