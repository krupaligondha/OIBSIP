# 🏠 House Price Prediction — Linear Regression

## 📌 Project Overview

This project uses **Linear Regression** to predict house prices based on features such as area, location, number of rooms, and house age.

## 🎯 Objectives

- Perform EDA and data cleaning
- Analyze factors affecting house prices
- Handle missing values and categorical features
- Encode categorical variables using One-Hot Encoding
- Build a Linear Regression model
- Evaluate model performance using MSE, RMSE, and R²
- Analyze model coefficients
- Visualize actual vs predicted prices and residuals
- Compare Linear Regression with Ridge/Lasso regression

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis & Visualizations

The project includes:

- Target Variable (Price) Distribution
- Correlation Heatmap
- Actual vs Predicted Prices
- Residual Plot
- Feature Coefficient Analysis

## 🤖 Machine Learning

### Model Used

**Linear Regression**

The dataset is divided into:

- **80% Training Data**
- **20% Testing Data**

### Evaluation Metrics

- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 💡 Key Insights

The project identifies:

- Important features influencing house prices
- Features with positive and negative impact on price
- How accurately the model predicts house prices
- Whether model residuals show any systematic patterns

## 🚀 Bonus

Linear Regression is compared with a regularized model such as:

- Ridge Regression
- Lasso Regression

This comparison helps determine whether regularization improves prediction performance.
